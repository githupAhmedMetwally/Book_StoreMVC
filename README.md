# 📚 Book Store MVC

A full-stack ASP.NET MVC web application that allows users to register, browse books, borrow and return them. Admins can manage books, categories, authors, and publishers.

---

## 🚀 Features

- 🔐 Authentication and role-based access (Admin & Customer)
- 📖 Browse books by title and category
- 👤 User profile edit and phone number update
- 📦 Borrow and return books with one click
- 🧾 View current borrowed books for each user
- 🧑‍💼 Admin dashboard to manage:
  - Categories
  - Books
  - Authors
  - Publishers

---

## 🛠️ Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap 5
- Identity (UserManager, SignInManager)
- Git & GitHub
